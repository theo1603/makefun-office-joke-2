One-line office joke writer: a Python program that writes a single original joke about office life (109 characters, one line) to `/output/entry.txt` for make.fun's "One-Line Office Joke: 24-Hour Sprint" bounty, $2 in USDC. The joke: IT answers a request for a second monitor with a mirror and a sticky note telling the requester to reflect on their productivity. Deterministic, dependency-free, no network.

## Run it

```sh
python3 main.py
```

`main.py` writes the joke to `/output/entry.txt` (109 characters, one line).
